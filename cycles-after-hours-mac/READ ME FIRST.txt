Blender @BLENDER_LABEL@ + Cycles After Hours Viewport Motion Blur v0.2.1
for Apple Silicon Macs (M1 or newer, macOS 11.2 or later)

INSTALL
1. Drag "@APP_NAME@" into the Applications folder.
   It has its own name, so it will not replace a normal Blender install.

2. The first time, macOS will refuse to open it because this build is not
   signed by an Apple-registered developer. To allow it:
     - Double-click the app and click "Done" on the warning, then
     - open System Settings > Privacy & Security, scroll down and click
       "Open Anyway" next to "@APP_NAME@".
   Or, in Terminal:
     xattr -dr com.apple.quarantine "/Applications/@APP_NAME@.app"

USE
1. Choose Cycles as the render engine.
2. Render Properties > Motion Blur: turn on Motion Blur, then tick
   "Viewport Motion Blur".
3. Switch the 3D Viewport to Rendered shading.

For the GPU, set Edit > Preferences > System > Cycles Render Devices to
Metal. The first Metal render compiles kernels and can take a few minutes.

NOTES
- This is an unofficial build, not affiliated with the Blender Foundation.
- It shares preferences and add-ons with any official Blender of the same
  version (for example 5.2 with 5.2), because both use the same settings
  folder: ~/Library/Application Support/Blender/<version>.
- The upstream patches were tested on Windows with CPU, CUDA and OptiX.
  The Mac build uses the same code, but Metal has not been tested by the
  patch author.
- An "alpha" Blender is a development snapshot: expect bugs, and keep
  backups of files you open with it.
